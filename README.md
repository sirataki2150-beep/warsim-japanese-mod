# Warsim 日本語化MOD(非公式)

「Warsim: The Realm of Aslona」(Huw Millward 作、Steam で販売)を、**ゲームの画面そのまま日本語で**遊べるようにする、非公式の日本語化パッチです。

- メニュー・語り・出来事・助言・戦闘報告などの文(文の型 約2万6千)と、人・国・町の名前(約9千4百語)を日本語にします。
- 別の窓に訳を出す形ではなく、ゲームの画面が日本語になります。入力もいつもどおりゲームの画面で行います。
- インターネットは使いません。日本語化はすべてパソコンの中で行います。
- いつでも外せます。外すと、元の英語の Warsim.exe とまったく同じ物に戻ります。
- セーブはそのまま使えます(日本語化で遊んだセーブも、英語版で続きから遊べます)。

> この配布物には、ゲームのプログラム本体(Warsim.exe)は入っていません。ゲームとの差分だけが入っていて、あなたのパソコンの中で、あなたのゲームに当てます。遊ぶには Steam で買った Warsim が必要です。

## 対応している版

- Steam 版の build 25097075(Warsim.exe の SHA-256 `93d159754192876538b175b1a50a515e256806dce9f03e2d7f50a32880686e5f`)
- ゲームが更新されて版が変わると、入れる前に「ゲームの版が合わない」と出て止まります(ゲームは壊れません)。

## ダウンロード

右の「Releases」(または [こちら](https://github.com/sirataki2150-beep/warsim-japanese-mod/releases/latest))から `Warsim_Japanese_MOD_1.0.zip` をダウンロードしてください。
(SHA-256 `36e7fe69c71e75f7832f62be0366f4479d622a94ae78916c3668b6046306cc58`)

## 入れ方(5分ほど)

1. **ZIP を展開する**: ダウンロードした `Warsim_Japanese_MOD_1.0.zip` を右クリック →「プロパティ」→ 下の「許可する」に印を入れて「OK」(欄が無ければそのまま)。もう一度右クリック →「すべて展開」→「展開」。
2. **ゲームのフォルダを開く**: Steam の「ライブラリ」で Warsim を右クリック →「管理」→「ローカルファイルを閲覧」。
3. **日本語化のフォルダを入れる**: 展開してできた「Warsim日本語化MOD」フォルダを、開いたゲームのフォルダの中へドラッグ。
4. **日本語化を入れる**: ゲームを閉じてから、「Warsim日本語化MOD」の中の「日本語化を入れる.cmd」をダブルクリック。
   青い画面「Windows によって PC が保護されました」が出たら「詳細情報」→「実行」。黒い画面に「日本語化を入れました。」と出れば成功。何かキーを押して閉じる。
5. **遊ぶ**: いつもどおり Steam で「プレイ」。

外すときは、ゲームを閉じてから「日本語化を外す.cmd」をダブルクリックします。
くわしくは ZIP の中の「はじめに読んでください.txt」を読んでください(うまくいかないときの対処も書いてあります)。

## ゲームの出力を1行ずつ Google 翻訳にかける方式とのちがい

ゲームの出力を1行ずつ Google 翻訳に送って別の窓に出す方式と、同じ場面の画面22枚を並べて比べました(英語版と日本語版を同じ乱数で動かし、同じ操作をして、同じ場面をそろえた物)。

- 文の途中で行が切れていても、文ごとに訳してあるので、意味が壊れません。
  (1行ずつ訳す方式では、たとえば「…and can / also ignore the ceremony completely.」が「式典も完全に無視してください。」と命令に変わるなど、行の切れ目で意味が壊れることがあります)
- 「金貨」「兵」「領地」「民衆の支持」などの言葉を、ゲーム全体でそろえています。
- 文字で描いた絵は、そのまま残します。
- ゲームの画面そのものが日本語になり、インターネットも使いません。

比べた22画面を、どちらがどちらか伏せて自動の採点にかけたところ、この日本語化の方が良い 14画面、同じくらい 6画面、1行ずつ訳す方式の方が良い 2画面でした(そのうち1画面の原因の誤りは、この版で直しています)。

## 分かっている不具合

- 年末の知らせや冒険者の知らせなど、一部の文や句が英語のまま出ることがあります(ゲームが英語の部品をつなぎ合わせて作る文)。
- ゲームがその場で作る人名などは、つづりからカタカナにしているため、読みが不自然なことがあります。
- 名前を差し込む所で、言い回しや改行が不自然になることがあります。
- Windows の「ベータ: ワールドワイド言語サポートで Unicode UTF-8 を使用」に印が入っているパソコンでは、まだ確かめていません。

おかしな訳を見つけたら知らせてください。
